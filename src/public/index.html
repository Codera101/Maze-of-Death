HOW TO PLAY ?

  1. CONTROLS

    • Arrow / WASD Keys

    • Shoot: Spacebar / Left Mouse Button

  2. GAME RULES

    • You start with 25 health points and refillable 5 bullets

    • When health reaches 0, you're eliminated and respawn after 3 seconds

    • You can only see and shoot players directly in front of you

    • Each successful hit: +5 points for you, -5 points for the target
